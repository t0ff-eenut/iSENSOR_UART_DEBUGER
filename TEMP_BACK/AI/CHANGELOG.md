## v1.0 — 초기 구현

**날짜:** 2026-04-21

### 구성
| 항목 | 값 |
|---|---|
| 은닉층 | `[64, 32]` (2개) |
| 에폭 | 100 |
| 학습률 | `1e-3` |
| 드롭아웃 | 0.3 |
| 배치 크기 | 16 |
| 스케줄러 | 없음 |

### 학습 결과
| 지표 | 값 |
|---|---|
| 최고 검증 정확도 | 97.0% (에폭 90) |
| 최종 검증 정확도 | 96.5% |
| 사람 놓침 (FN) | 134건 |
| 오경보 (FP) | 77건 |

### 분석
- 에폭 100 끝까지 손실이 계속 하강 중 → **아직 수렴 전**
- 학습/검증 차이 0.7%p → 과적합 없음
- 사람 놓침(FN) 134건이 오경보(FP) 77건보다 많음 → 재실 감지에서 위험한 오류

## v2.0 — 에폭 확장 + 학습률 조정

**날짜:** 2026-04-21

### 변경 원인
- v1.0에서 손실이 수렴하지 않은 채 학습 종료
- 학습률 `1e-3`이 후반 세밀한 수렴에 너무 큼

### 변경 내용
| 항목 | 이전 | 이후 |
|---|---|---|
| 에폭 | 100 | **200** |
| 학습률 | `1e-3` | **`5e-4`** |
| 은닉층 | `[64, 32]` | `[64, 32]` (유지) |

### 학습 결과
| 지표 | v1.0 | v2.0 | 변화 |
|---|---|---|---|
| 최고 검증 정확도 | 97.0% | **97.1%** | +0.1%p |
| 최종 검증 정확도 | 96.5% | **97.1%** | +0.6%p |
| 사람 놓침 (FN) | 134건 | **85건** | **-37%** |
| 오경보 (FP) | 77건 | 89건 | +12건 |
| 배경 정밀도 | 0.948 | **0.966** | +0.018 |
| 사람 재현율 | 0.962 | **0.976** | +0.014 |

### 혼동 행렬
```
               예측: 배경   예측: 사람
실제: 배경      2437         89
실제: 사람        85       3418
```

### 분석
- 핵심 지표인 **사람 놓침(FN) 37% 감소** — 재실 감지 신뢰도 개선
- 200에폭 후반부에서도 손실이 완만하게 하강 중 → 추가 개선 여지 있음
- 학습/검증 차이 0.7%p 유지 → 과적합 없음

## v3.0 — 은닉층 확장 + 학습률 스케줄러 추가

**날짜:** 2026-04-22

### 변경 원인
- v2.0에서 과적합이 없으므로 모델 용량 확장 여지 있음
- 200에폭 후반 손실 정체 구간에서 학습률 자동 조절 필요

### 변경 내용
| 항목 | 이전 | 이후 |
|---|---|---|
| 은닉층 | `[64, 32]` | **`[128, 64, 32]`** |
| 학습률 스케줄러 | 없음 | **ReduceLROnPlateau** |
| 스케줄러 patience | - | 10 에폭 |
| 스케줄러 factor | - | 0.5 (정체 시 lr 절반) |

### ReduceLROnPlateau 동작 방식
```
손실이 10에폭 동안 줄지 않으면:
  5.00e-04 → 2.50e-04 → 1.25e-04 → ... (최소 1e-6)
```

### 현재 하이퍼파라미터
```python
EPOCHS               = 200
BATCH_SIZE           = 16
LEARNING_RATE        = 5e-4   # 초기값 (스케줄러가 자동 조절)
HIDDEN_LAYERS        = [128, 64, 32]
DROPOUT_RATE         = 0.3
LR_SCHEDULER_PATIENCE = 10
LR_SCHEDULER_FACTOR   = 0.5
```

```python

HIDDEN_LAYERS = [64, 32] # 구조 축소
```

### 과소적합 발생 시 (정확도 낮음)
```python
HIDDEN_LAYERS = [128, 64, 32]  # 구조 확장
EPOCHS        = 300            # 에폭 증가
```

### 손실 정체 시
```python
LR_SCHEDULER_PATIENCE = 5   # 더 빠르게 lr 감소
```
