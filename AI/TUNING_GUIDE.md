## 1. 추가 특징 입력 여부 (ADC 300개 + FFT 300개)

### 상황
- 현재 입력: SVM이 선택한 **24개 FFT 특징** (`A_feature_indices`)
- 제안: ADC 원시값 300개 + FFT 전체 300개 추가 → **입력 24 → 624 (26배 증가)**

### 결론: 신중하게 접근 필요

#### 기대 효과
- 원시 신호를 직접 넣으면 모델이 스스로 패턴을 찾을 수 있음
- PCA 분리도가 이론적으로 개선될 가능성 있음

#### 문제점

| 문제 | 설명 |
|---|---|
| **노이즈 증가** | ADC 300개 중 의미있는 값은 일부 — 나머지가 오히려 학습을 방해 |
| **차원의 저주** | 특징이 26배 늘었는데 데이터(24,115행)는 그대로 → 과적합 위험 |
| **학습 속도 저하** | 입력층 가중치가 24배 늘어남 |
| **PCA 설명력 하락 가능** | 무의미한 차원이 많을수록 PC1+PC2 설명력이 낮아짐 |

#### 현재 24개 특징이 이미 좋은 이유
SVM이 고른 24개는 FFT에서 **가장 판별력 높은 주파수 빈(bin)** 들입니다.  
이미 정보가 압축된 상태이므로 원시값을 그대로 추가해도 새로운 정보가 많지 않습니다.

#### 그래도 시도하고 싶다면
전체를 넣는 것보다 **추가 특징을 먼저 선별**하는 것이 효율적입니다:
```python

# 예: 이미 깔끔하게 분리된다면 → 추가 불필요
```

## 2. 첫 번째 은닉층 128 → 256 확장 여부

### 결론: 효과 제한적, 권장하지 않음

#### 이유

```
입력 24개 → 128 뉴런  (이미 5.3배 확장)
입력 24개 → 256 뉴런  (10.7배 확장)
```

- 입력 24개에 256 뉴런은 **과도한 확장** — 학습 시간만 증가
- 현재 97.1%는 이 데이터셋/특징 수 기준으로 이미 포화에 가까운 성능
- 학습/검증 차이가 0.7%p 수준 → 모델이 작아서 성능이 부족한 상황이 아님
- 256으로 늘리면 과적합 위험만 증가할 가능성이 높음

#### 더 효과적인 방향

| 방법 | 기대 효과 | 난이도 |
|---|---|---|
| 더 많은 데이터 수집 | 높음 | 높음 |
| 사람 클래스 가중치 부여 (`class_weight`) | FN 감소 | 낮음 |
| 데이터 증강 (노이즈 추가) | 중간 | 중간 |
| v3.0 [128,64,32] 결과 확인 후 판단 | 기준선 수립 | 진행 중 |

## 3. 출력층 직전 전환 (32 → 2) 세분화 여부

### 상황
- 현재 마지막 은닉층: 32 뉴런 → 출력: 2 클래스
- 질문: 32 → 16 → 2 처럼 중간 단계를 추가해야 할까?

### 결론: 불필요, 현재 구조가 이상적

#### 이유
- 출력층 직전은 **"분류 헤드"** 역할로, 마지막 은닉층 특징을 클래스 점수로 변환하는 단계
- 32 → 2 직접 연결은 매우 표준적인 패턴 (ResNet, BERT 등 모두 동일)
- 32 → 16 → 2 로 층을 추가하면:
  - 역전파 시 **기울기 소실(Vanishing Gradient)** 위험 증가
  - 입력 24개짜리 소형 문제에서 레이어가 과도하게 깊어짐
  - 수렴 속도만 느려지고 정확도 개선 없음

#### 현재 구조가 이상적인 이유
```
입력(24) → 128 → 64 → 32 → 출력(2)
```
**절반씩 줄어드는 깔때기(funnel) 구조** — 각 층이 점진적으로 추상화하며
마지막 32개 특징이 2개 클래스로 자연스럽게 수렴합니다.

## 4. 다음 시도 우선순위

v3.0 ([128,64,32] + ReduceLROnPlateau) 결과 확인 후 판단:

1. **FN(False Negative)이 여전히 많다면** → `class_weight` 추가 (사람 클래스에 가중치 부여)
2. **과적합이 발생한다면** → `DROPOUT_RATE` 0.3 → 0.4 증가
3. **손실이 정체된다면** → `LR_SCHEDULER_PATIENCE` 10 → 5로 축소
4. **그래도 성능 한계라면** → 추가 데이터 수집 후 재학습

## 5. PCA 설명력 (2PC Explained Variance Ratio)

### 개념
PCA(주성분 분석)로 고차원 데이터를 2D로 압축할 때, **원본 정보를 얼마나 보존했는지**를 나타내는 비율.

```
원본 데이터: 24차원 (특징 24개)
         ↓ PCA
시각화용: 2차원 (PC1, PC2)

PC1 설명력 = 45%  → PC1 축 하나가 전체 데이터 분산의 45%를 설명
PC2 설명력 = 20%  → PC2 축 하나가 추가로 20%를 설명
──────────────────────────────
PC1 + PC2 합계 = 65%  ← 이게 "2PC 설명력"
```

### 해석 기준

| 2PC 합계 | 의미 |
|---|---|
| 80% 이상 | 2D 시각화가 원본을 잘 대표함 |
| 60~80% | 어느 정도 신뢰 가능 |
| 60% 미만 | 2D로 표현 시 많은 정보 손실 → 분리가 흐릿해 보여도 실제로는 잘 분리될 수 있음 |

### 시각화에서 확인하는 방법
`visualize.py`의 PCA 분포도 그래프 제목에 `PC1 XX% / PC2 XX%` 형태로 표시됨.
BG/Human 두 클러스터가 시각적으로 겹쳐 보여도 설명력이 낮으면 나머지 차원에서는 충분히 분리되고 있을 수 있음.

### ADC/FFT 특징 추가 시 영향
- 무의미한 차원이 많아질수록 PC1+PC2 설명력이 낮아질 수 있음
- 설명력이 낮아지면 PCA 그래프만 보고 분리도를 판단하기 어려워짐
- 추가 특징 투입 전후로 설명력 변화를 비교하는 것이 좋은 판단 기준
